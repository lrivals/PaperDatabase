# PaperDatabase research answers

For questions about papers in this repository, follow the evidence workflow in `.claude/commands/paper-ask.md` with `bin/pdb bench`, `search`, `show` and `verify` (CPU by default; `search` switches itself to the Qwen models when the user has turned the GPU route on with `bin/pdb gpu on`). Use `bin/pdb rag` and `.claude/commands/paper-research.md` only when the user asks for the GPU route and `bin/pdb gpu` reports a CUDA GPU (docs/RAG.md §13). Keep original-paper passages, benchmark transcriptions, and curated notes distinct. Verify numerical comparison conditions and qualify missing evidence. Open-access acquisition only stages papers; import them (`bin/pdb rag approve`) only after the user accepts them, and report it. For ordinary code work, use the project's existing development workflow.
